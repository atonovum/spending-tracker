# SpendingTracker 기획 요약

## 목표
- iPhone 15 Pro / iPad 11인치 대응 반응형 가계부
- 웹 + 앱 하이브리드 사용(PWA: 홈 화면 설치, 오프라인 캐시)
- UI는 Vite + React + Mantine + Tailwind CSS 기반

## 정보 구조
- 메뉴: `Ledger`, `Stats`, `Search`, `Settings`
- 하단 고정 탭 네비게이션
- 상단 공통 필터: `지갑 선택`, `기간 선택`

## 핵심 개념
- 지갑 = 1인당 계좌 단위
- 최대 5개 지갑
- 기본 지갑 1개 자동 생성
- Import / Export는 지갑 단위(JSON)

## 거래 데이터 모델
- 필드: `카테고리`, `레이블`, `날짜`, `노트`, `반복`, `금액`
- 반복 옵션: `없음`, `매일`, `1주일`, `2주일`, `한달`
- 카테고리는 `수입/지출` 타입을 가지며 통계/그래프에 사용

## 화면별 기능

### Ledger
- 요약 카드: 총 남은 현금, 기간내 총 현금 흐름
- 상단 기간 선택: `By weeks`, `By months`, `By years` (디폴트: `By months`)
- 카드 클릭 그래프 전환
  - `총 남은 현금` 클릭: 누적 현금 흐름 꺾은선
  - `기간내 총 현금 흐름` 클릭: 수입/지출 막대(수입 위, 지출 아래)
- 기간내 총 현금 흐름 계산 기간: `7일`, `30일`, `1년`
- 그래프 히스토리 좌/우 이동 버튼
- 막대 클릭 시 해당 기간의 일별 거래 목록 표시
- 일별 거래 목록(카테고리 색상 표시)
- Add/Edit 폼(모바일: 열기 버튼, 데스크톱/태블릿 대화면: 우측 고정 패널)

### Stats
- Ledger와 동일한 요약 카드(총 남은 현금, 기간내 총 현금 흐름)
- 기간 탭: 선택 기간 기준(주/월/년)으로 첫 거래일부터 현재까지 구간 탭 제공
- 레이블 통계: 금액 클릭 시 해당 레이블로 카테고리 통계 필터
- 카테고리 통계:
  - 디폴트: 레이블 무관 카테고리 집계
  - 필터 상태 표시 + `디폴트` 버튼으로 필터 해제
  - `총 수입` / `총 지출` 버튼으로 파이그래프 전환

### Search
- 기간 필터 + 텍스트 검색(카테고리/레이블/노트)
- 결과 목록은 Ledger 스타일 재사용

### Settings
- 지갑 추가/이름변경/삭제
- 선택 지갑 Export / Import
- 카테고리 커스터마이징(추가/이름변경/삭제)
- 레이블 커스터마이징(추가/이름변경/삭제)

## 기술 선택
- Vite + React
- Mantine + Tailwind CSS
- 로컬 저장소: `localStorage`
- PWA: `vite-plugin-pwa` 기준으로 manifest/service worker 구성
